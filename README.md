# 📁 CRUD - Sistema de Gerenciamento de Documentos

Sistema de gerenciamento de documentos desenvolvido em **C**, criado para praticar habilidades de programação com foco em estruturas de dados, manipulação de arquivos e lógica de programação.

---

## 🚀 Funcionalidades

- **Cadastrar** documentos com nome, RG, tipo, data de vencimento e titularidade
- **Buscar** documentos pelo código
- **Alterar** data de vencimento e titularidade de documentos
- **Remover** documentos do sistema
- **Salvar e recuperar** dados entre sessões através de arquivos

---

## 🛠️ Tecnologias utilizadas

- Linguagem **C**
- Estrutura de dados: **Árvore Binária de Busca**
- Manipulação de **arquivos** (leitura e escrita)
- Alocação dinâmica de memória com **malloc**

---

## ▶️ Como rodar

### Pré-requisitos
- GCC instalado ([MSYS2](https://www.msys2.org/) no Windows)

### Compilar e executar

```bash
gcc trabalho_pratico.c -o crud
./crud
```

### Menu do sistema

```
O que deseja fazer?
[1] Cadastrar um novo documento
[2] Excluir um documento
[3] Alterar os dados em um documento
[4] Buscar documento
[5] Sair e arquivar dados
```

---

## 📚 O que aprendi

- Implementação de **árvore binária de busca** com inserção, remoção e busca
- Uso de **structs** e **ponteiros** em C
- Persistência de dados com **leitura e escrita em arquivos**
- Organização de código com **funções modulares**
